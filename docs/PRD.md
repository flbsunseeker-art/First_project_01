# StockPilot PRD

## 0. 文档信息

- 产品名称：StockPilot
- 当前阶段：MVP
- 运行形态：本地运行的个人股票持仓与收益管理工具
- 文档状态：已对齐，作为后续 Design、Architecture、TODO 和验收来源

## 1. 产品一句话

StockPilot 是一个面向多市场股票投资者的本地持仓与收益管理工具，帮助用户用人民币统一看清 A 股、港股、美股的持仓现状、收益变化、行业/市场分布，并记录交易理由以便后续复盘。

## 2. 项目背景

用户在 A 股、港股、美股等多个市场持有股票，但持仓分散在不同券商 APP 中，无法统一查看整体持仓、收益变化、行业分布和市场分布。

本项目第一期通过本地运行、手动维护的方式，验证「多市场统一持仓与收益管理」的核心价值。长期可演进为小程序、Web App 或移动 App，服务更多有类似需求的个人投资者。

## 3. 目标用户

核心用户是有多个市场股票持仓，希望统一管理股票收益和仓位结构的个人投资者。

用户特征：

- 同时持有 A 股、港股、美股中的一种或多种；
- 股票分散在不同券商 APP 中；
- 希望统一查看总市值、今日收益、累计收益；
- 第一阶段可接受手动维护持仓和交易；
- 关注行业分布、市场分布和持仓集中度；
- 希望记录买卖理由，方便未来复盘决策质量。

## 4. 核心痛点

1. **持仓分散**：不同券商 APP 只能展示局部持仓，无法看清整体收益。
2. **币种不统一**：A 股、港股、美股计价货币不同，缺少人民币统一口径。
3. **结构不清晰**：用户难以判断资金主要分布在哪些市场、行业和个股。
4. **收益变化难追踪**：缺少每日收益和股票总市值变化视图，难以理解账户长期变化。
5. **交易难复盘**：买卖理由没有被结构化记录，后续难以复盘决策质量。

## 5. 产品价值主张

StockPilot 不做券商替代和投资建议，而是提供一个轻量、可信、可解释的个人股票总账：

- 以人民币统一汇总多市场股票持仓；
- 通过行情和汇率补齐每日估值；
- 用总览、持仓列表、收益日历和趋势图快速看清资产变化；
- 用行业分布和市场分布发现仓位结构问题；
- 用交易理由和备注沉淀个人投资决策记录。

## 6. MVP 目标

第一期聚焦「看清现状」和「定位问题」，不做复杂投资建议。

MVP 需要让用户完成：

- 录入并维护当前股票持仓；
- 记录后续买入、卖出交易；
- 记录每次交易的理由分类和备注；
- 统一查看人民币口径总市值、今日收益和累计收益；
- 查看每只股票的盈亏、涨跌和仓位占比；
- 查看行业分布和市场分布；
- 查看每日收益变化、收益日历和总市值趋势；
- 在行情、汇率或估值异常时知道数据不可信。

### 6.1 当前迭代目标：可信日常使用版

当前版本优先完成两件事：每天看清资产状态，交易后完成记录与复盘。

核心验收：

- 打开产品后，30 秒内知道总资产、当日变化、主要盈亏来源和数据截止时间；
- 最新行情、汇率或快照缺失时明确提示，不以默认值或空数据伪装正常结果；
- 录入一笔交易后，持仓、成本、收益和受影响日期后的历史快照一致更新；
- 在移动端可以查看交易历史、交易理由和备注；
- 可以从收益日历进入单日详情，解释当日资产变化来自哪些持仓和交易。

当前版本不扩展到投资建议、券商直连、现金、手续费、分红或复杂归因。

## 7. MVP 功能范围

### 7.0 页面导航

顶部使用横向 Tab 导航。

顺序：

1. 总览
2. 持仓
3. 收益
4. 交易
5. 数据

### 7.1 证券管理

用户可以新增和编辑证券信息。

字段：

- 股票代码
- 股票名称
- 所属市场：A 股 / 港股 / 美股
- 计价币种：CNY / HKD / USD
- 所属行业

规则：

- A 股默认 CNY；
- 港股默认 HKD；
- 美股默认 USD；
- 行业可自动识别，也可手动修改；
- 手动修改后的行业优先，不被自动识别覆盖；
- 已清仓证券保留基础信息和历史交易，但不计入当前持仓。

### 7.2 初始持仓维护

用户可以录入当前已有持仓，作为系统可信起点。

字段：

- 股票
- 当前持仓股数
- 平均成本价
- 起始日期

规则：

- 不强制用户补录历史全部交易；
- 起始日期前的历史收益不追溯计算；
- 起始日期当天作为基线日，默认不计算当日收益；
- 起始日期后的仓位变化通过交易记录维护。

### 7.3 手动交易记录

用户可以记录买入和卖出交易。

交易入口需要先区分交易对象：

- 已有股票：从当前已维护或当前持仓内的股票下拉选择；
- 新股票：先填写完整证券基础信息，再录入交易。

字段：

- 股票，已有股票下拉选择或新股票基础信息
- 新股票代码
- 新股票名称
- 新股票所属市场：A 股 / 港股 / 美股
- 新股票计价币种：CNY / HKD / USD
- 新股票所属行业
- 交易方向：买入 / 卖出
- 交易日期
- 股数
- 成交价格
- 交易理由分类
- 备注

交易理由分类：

1. 行业趋势判断
2. 个股基本面
3. 价格 / 估值判断
4. 仓位 / 情绪管理

规则：

- MVP 阶段交易理由分类固定为以上四类，备注用于补充自由文本；
- 交易理由在页面中使用下拉单选，不让用户自由输入分类；
- 成交价格按股票所属市场币种录入；
- 股数和成交价格默认展示和录入精度为小数点后两位；
- 买入增加持仓；
- 卖出减少持仓；
- 不支持卖出超过当前持仓；
- 不支持做空；
- 同日多笔交易按录入顺序计算；
- 交易修改或删除后，系统需要从受影响日期开始重算后续持仓和收益。

### 7.4 行情与汇率

系统获取最新行情和汇率，并按人民币统一估值。

规则：

- A 股使用人民币价格；
- 港股使用港币价格，并按 HKD/CNY 折算；
- 美股使用美元价格，并按 USD/CNY 折算；
- 历史估值使用对应日期的收盘价和历史汇率；
- 某市场休市时，持仓估值沿用该证券最近有效收盘价；
- 行情或汇率缺失时，明确展示异常状态；
- 不生成缺少关键数据但看似准确的收益结果。

### 7.5 持仓与收益计算

单只股票指标：

- 所属市场
- 股票名称
- 股票代码
- 所属行业
- 成本价格
- 最新价格
- 币种
- 当前股数
- 持仓成本，按人民币计价
- 当前人民币市值
- 累计收益金额，按人民币计价
- 累计收益率，按人民币计价
- 今日涨跌金额
- 今日涨跌幅
- 仓位占比

组合指标：

- 当前股票总市值
- 总持仓成本
- 累计收益金额
- 累计收益率
- 今日收益金额
- 今日收益率

收益口径：

- 当前股票总市值 = 当前持仓股票按最新价格和汇率折算后的人民币市值之和；
- 总持仓成本 = 当前仍持有股票的剩余成本，按当前估值汇率折算人民币；
- 累计收益金额 = 已实现收益 + 未实现收益；
- 累计收益率 = 累计收益金额 / 总持仓成本；
- 今日收益金额 = 今日股票总市值 - 上一估值日股票总市值 - 今日买入金额 + 今日卖出金额；
- 今日收益率 = 今日收益金额 / 上一估值日股票总市值；
- 每日收益率 = 当日收益金额 / 上一估值日股票总市值。

颜色规则：

- 红色：上涨 / 盈利；
- 绿色：下跌 / 亏损。

### 7.6 首页总览

首页用于快速判断整体持仓状态。

页面头部：

- 产品名称：StockPilot
- 产品描述：聚合 A 股、港股、美股持仓，统一追踪收益、仓位与行业分布，并提供面向市场趋势的持仓洞察

展示：

- 总持仓市值
- 总持仓成本
- 累计收益金额
- 累计收益率
- 今日收益金额
- 今日收益率
- 数据更新时间
- 总市值变化趋势，用折线图展示

布局规则：

- 总市值变化趋势左侧展示折线图；
- 趋势明细表格放在折线图右侧；
- 首页不展示冗余营销型内容，优先展示产品名称、描述和核心指标。
- 总市值变化趋势从 2026-05-11 开始回溯，避免趋势周期过短。

### 7.7 持仓列表

展示每只股票的当前状态。

字段：

- 序号
- 所属市场
- 股票名称
- 股票代码
- 所属行业
- 成本价格
- 最新价格
- 币种
- 持仓股数
- 持仓成本，按人民币价格计价
- 最新市值，按人民币价格计价
- 累计收益金额，按人民币价格计价
- 累计收益率，按人民币价格计价
- 今日收益金额，按人民币价格计价
- 今日收益率，按人民币价格计价
- 仓位占比

展示规则：

- 持仓明细先按所属市场聚类排列，顺序为 A 股、港股、美股；
- 序号列体现当前总共有多少只股票；
- 行业列只展示所属行业，不在持仓明细表内编辑；
- 持仓明细表内不提供行业保存操作；
- 金额和百分比默认保留小数点后两位。

基础排序：

- 按市值排序
- 按累计收益金额排序
- 按累计收益率排序
- 按今日收益排序
- 按仓位占比排序

### 7.8 行业分布

按当前人民币市值统计行业分布，显示在持仓明细表下方。

展示：

- 行业分布饼状图
- 行业名称
- 行业持仓金额
- 行业占比
- 行业内股票列表

规则：

- 已清仓股票不计入当前行业分布；
- 行业分布金额之和等于当前股票总市值；
- 行业占比之和为 100%；
- 行业分布金额和百分比保留小数点后两位；
- 无法识别行业的股票归为「其他」。

### 7.9 市场分布

按当前人民币市值统计市场分布，显示在持仓明细表下方。

展示：

- 市场分布饼状图
- A 股市值及占比
- 港股市值及占比
- 美股市值及占比

规则：

- 市场分布金额之和等于当前股票总市值；
- 市场占比之和为 100%；
- 市场分布金额和百分比保留小数点后两位。

### 7.10 每日收益

展示每日组合收益变化。

MVP 至少支持以下一种形式：

- 每日收益列表
- 每日收益柱状图

字段：

- 日期
- 当日收益金额
- 当日收益率

规则：

- 红色表示当日盈利；
- 绿色表示当日亏损；
- 行情或汇率缺失日期需要标记异常；
- 趋势明细表格不展示状态列，异常状态通过收益日历标记或数据状态区域展示。

### 7.11 收益日历月视图

MVP 需要支持月视图收益日历。

展示：

- 按自然月展示每日收益金额；
- 展示每一天对应的星期；
- 支持切换月份；
- 盈利日期用红色；
- 亏损日期用绿色；
- 无数据或数据异常日期需要明确标记；
- 点击日期后展示当日收益明细。

暂不支持：

- 复杂周视图；
- 日内收益视图；
- 复杂收益归因。

### 7.12 总市值趋势图

按日展示组合总市值变化。

展示：

- 日期
- 股票总市值

第一期只做总市值趋势，不做复杂归因分析。

### 7.13 数据状态

系统需要清晰展示数据是否完整可信。

状态内容：

- 行情更新时间
- 汇率更新时间
- 是否存在行情缺失
- 是否存在汇率缺失
- 是否存在估值失败
- 当前数据是否为最新数据

### 7.14 导入导出与备份

MVP 需要支持基础数据安全和迁移能力。

功能：

- 交易记录 CSV 导入；
- 交易记录 CSV 导出；
- 本地 SQLite 数据库备份；
- HTML 报告导出。

规则：

- 导入失败时需要指出失败行和原因；
- 备份文件保存在本地，不自动上传；
- HTML 报告需要包含总览、持仓、行业分布和市场分布。

## 9. 核心用户流程

### 9.1 首次使用

1. 用户打开应用；
2. 新增股票基础信息；
3. 录入当前持仓股数、平均成本和起始日期；
4. 系统获取最新行情和汇率；
5. 系统展示首页总览、持仓列表、行业分布和市场分布。

### 9.2 日常查看

1. 用户打开应用；
2. 系统更新最新行情和汇率；
3. 系统补齐缺失的历史估值；
4. 用户查看今日收益、累计收益和总市值；
5. 用户查看单只股票涨跌；
6. 用户查看行业分布、市场分布、收益日历和总市值趋势。

### 9.3 发生交易

1. 用户新增买入或卖出记录；
2. 选择使用已有股票或创建新股票；
3. 如果使用已有股票，从下拉列表选择当前已维护或当前持仓内的股票；
4. 如果创建新股票，先填写股票代码、名称、市场、币种和行业；
5. 输入交易日期、股数和成交价格；
6. 通过下拉单选选择交易理由分类；
7. 输入可选备注；
8. 系统更新持仓、成本、收益和仓位占比；
9. 系统从交易日期开始重算后续快照。

### 9.4 查看交易复盘素材

1. 用户进入交易流水；
2. 按股票、日期或交易理由筛选；
3. 查看每笔交易的成交信息、理由分类和备注；
4. 作为后续交易复盘分析的原始素材。

## 10. 技术可行性初判

第一期技术方案整体可行。

建议技术栈：

- Next.js / React：Web 端与移动端响应式页面；
- FastAPI：后端 API、账本服务、估值服务和历史补算；
- Python：收益计算、数据处理、行情和汇率适配；
- SQLite：MVP 本地数据存储；
- PostgreSQL：未来云端、多用户或多设备同步时的迁移目标；
- 第三方行情源：获取 A 股、港股、美股行情；
- 汇率数据源：获取 HKD/CNY、USD/CNY。

主要风险：

- 不同市场行情数据源稳定性不同；
- 股票代码格式需要统一处理；
- 休市日、节假日、行情缺失会影响每日收益计算；
- 汇率缺失会影响港股和美股人民币估值；
- 修改历史交易后，需要保证后续持仓和收益一致重算；
- AI 分析过早引入，容易产生泛泛或不可靠建议。

第一阶段原则：

1. 先保证核算正确；
2. 再保证页面清楚；
3. 最后再考虑 AI 分析和投资洞察。

## 11. 验收标准

### 11.1 证券与持仓

- 可以新增和编辑 A 股、港股、美股；
- 可以录入当前持仓股数、平均成本和起始日期；
- 行业可以自动识别，也可以手动修改；
- 手动修改后的行业不会被自动识别覆盖。

### 11.2 交易记录

- 可以新增买入和卖出交易；
- 可以选择已有股票录入交易；
- 可以在交易填报中创建新股票并补齐基础信息；
- 可以记录交易理由分类和备注；
- 交易理由分类使用固定候选项下拉单选；
- 买入后持仓数量增加；
- 卖出后持仓数量减少；
- 卖出超过当前持仓时系统拒绝；
- 同日多笔交易按录入顺序计算。

### 11.3 收益计算

- 可以展示单只股票当前市值、收益金额、收益率；
- 可以展示组合总市值、累计收益、今日收益；
- 可以展示累计收益率和今日收益率；
- 港股和美股可以按汇率折算为人民币；
- 买入和卖出不会被错误计入每日市场收益；
- 行情或汇率缺失时，系统展示异常状态。

### 11.4 页面展示

- 顶部导航按总览、持仓、收益、交易、数据顺序展示；
- 首页可以展示产品名称、描述、核心总览指标和总市值折线图；
- 首页总市值趋势明细表格展示在折线图右侧；
- 持仓页可以展示每只股票的成本价格、最新价格、币种、收益、收益率和仓位；
- 持仓明细支持按市值、累计收益金额、累计收益率、今日收益和仓位占比排序；
- 持仓明细中的行业列只展示，不在表格内编辑；
- 行业分布以饼状图展示，金额之和等于总市值；
- 市场分布以饼状图展示，金额之和等于总市值；
- 每日收益列表或柱状图可以展示每日收益变化；
- 收益日历月视图可以展示每日收益、星期和月份切换；
- 总市值折线图可以展示每日总市值变化；
- 交易流水可以展示交易理由分类和备注。

### 11.5 数据一致性

- 首页、持仓列表、行业分布、市场分布、收益日历和趋势图使用同一套核算结果；
- 不同页面展示的总市值保持一致；
- 已清仓股票不计入当前持仓和当前行业分布；
- 缺失行情或汇率时，不生成伪准确收益；
- 修改或删除历史交易后，后续持仓和收益会一致重算。

### 11.6 数据安全

- 所有数据默认保存在本地 SQLite；
- 不自动上传持仓、交易、成本和收益数据；
- 联网行情查询只需要股票代码和日期范围；
- 用户明确要求前不提交、不推送 GitHub。
